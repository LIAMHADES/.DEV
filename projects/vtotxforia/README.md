# VtoTXforIA

Dictado por voz + transcripción local con Whisper.

## Web demo
`index.html` — demo en el navegador (Whisper WASM), sin enviar el audio a ningún servidor.

## App de escritorio (no publicada)
- Modelo `faster-whisper small` en local (CPU)
- Tecla global **F8** para grabar o pausar desde cualquier aplicación
- Indicador flotante de grabación, historial de sesiones y bandeja del sistema
- Escribe el texto directamente en la aplicación activa
