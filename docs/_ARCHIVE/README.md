# DOCUMENTOS OBSOLETOS

Esta carpeta contiene versiones históricas de los documentos del proyecto ARES GPS que YA NO ESTÁN VIGENTES.

La documentación ACTUAL está en:
- Producto/negocio/técnica: `docs\investigacion_tracker_diy\PRODUTO\ACTUAL\`
- Specs funcionales (v4.0): `docs\specs\v4_final\`
- Specs de app (bloques v1): `docs\investigacion_tracker_diy\APP\`

## Estructura

- `v3_investigacion/` — Investigación v3.x con hardware antiguo (GF-07, BG96, MPU6050, WS2812B) + planes de hardware obsoletos (v3 y v4.1) + comparativa de chips
- `v3_notas/` — Notas y specs antiguas (v0.2, v2 post-pivotaje, TODO APP concatenado v0.1, documento v3.6)
- `v2_v3_anteriores/` — Versiones v2.x y v3.x de especificaciones (LEDs, hardware, PCB)
- `v3_marketing/` — Plan de marketing v3.6 (precios antiguos, estrategias descartadas)
- `_DEPRECATED_old/` — Archivos más antiguos y base de datos inicial
- `_duplicados_revisar/` — Archivos duplicados de versiones anteriores, separados para comparar antes de decidir su destino

NO USAR ESTOS DOCUMENTOS PARA DESARROLLO ACTUAL.
Consultar `PRODUTO/ACTUAL/` y `specs/v4_final/` para la versión vigente (v4.0).
