# DESCARTADO — Carril deslizante + pin (tipo Fi Series / Garmin QuickFit)

**Concepto:** el tracker se desliza en un carril integrado y se retiene con un pin. Retención muy segura.

**Por qué era atractivo:** la retención más segura del mercado contra tirón; muy difícil de perder.

**Por qué se descartó (decisión explícita del usuario):**
- **NO es universal** — el carril está conceptualmente atado a un tipo de banda/collar concreto; no sirve igual de bien para cualquier collar Y cualquier arnés.
- **Patente activa** — Fi y Garmin tienen patentes de sus sistemas de carril; alto riesgo legal.
- **Molde caro** — el carril con latch metálico exige corredera + inserto, caro a baja escala.

**Motivo principal del usuario:** "no es apto para todos los tipos de collar y arnés; necesitamos algo versátil".
