# DESCARTADO — Imán magnético + lengüeta mecánica (tipo Peak Design)

**Concepto:** dos imanes N52 que atraen y autoalinean el tracker al soporte; una lengüeta mecánica es la que retiene de verdad (el imán solo posiciona).

**Por qué era atractivo:** el mejor para instalación a ciegas y para artritis (el imán hace el trabajo fino de alineación).

**Por qué se descartó:**
- **Imán caro** — encarece la pieza ~2-3€/unidad.
- **Frágil a agua salada** — el neodimio se oxida y se pulveriza si el encapsulado falla; ARES es IP68 y va a la playa/mar.
- **Peso** — los imanes suman ~3-4 g, malo para perros pequeños.
- **Patente activa** — Peak Design defiende agresivamente su sistema imán+lengüeta.

**Choca con las prioridades del usuario:** reparable/barato/antiatasco/ligero. El imán falla en coste, peso y robustez ambiental.
