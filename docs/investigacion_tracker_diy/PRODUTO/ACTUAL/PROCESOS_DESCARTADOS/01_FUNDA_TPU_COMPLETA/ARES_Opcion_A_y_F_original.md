# ARES — Sistema de Enganche: Descripción completa de Opciones

---

## OPCIÓN A — FUNDA TPU COMPLETA GEOMÉTRICA

### Cómo se ve

El tracker rectangular va introducido dentro de una funda de TPU (goma flexible) que lo envuelve por completo. La funda tiene:

- **Cara frontal (visible):** un marco de TPU de ~3mm de ancho que rodea el tracker dejando el centro visible. En las zonas de los chaflanes 45° de las L, la funda tiene **recortes** — como "ventanas" — para que la luz de los LEDs salga sin obstrucción.

```
VISTA FRONTAL (lo que ve el dueño):

┌──────────────────────────────────┐
│ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒  │  ← marco superior TPU (3mm)
│ ▒                                │
│ ▒        TRACKER (visible)       │
│ ▒        ┌──────┐               │
│ ▒        │ LED  │               │  ← L visible por recorte
│ ▒        │  L   │               │
│ ▒        └──────┘               │
│ ▒                                │
│ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒  │  ← marco inferior TPU
└──────────────────────────────────┘
```

- **Cara trasera (contra el collar):** una **celosía geométrica** (hexágonos, tipo panal de abeja) que forma 6-8 **pasadores independientes**. Cada pasador es un túnel por donde pasa el collar. Al ser independientes, si uno se rompe, los demás sujetan.

```
VISTA TRASERA (lo que ve el collar):

┌──────────────────────────────────┐
│  ╔══╗ ╔══╗ ╔══╗ ╔══╗ ╔══╗ ╔══╗ │
│  ║  ║ ║  ║ ║  ║ ║  ║ ║  ║ ║  ║ │  ← 6 túneles
│  ╚══╝ ╚══╝ ╚══╝ ╚══╝ ╚══╝ ╚══╝ │    independientes
│  ╔══╗ ╔══╗ ╔══╗ ╔══╗ ╔══╗ ╔══╗ │    para el collar
│  ║  ║ ║  ║ ║  ║ ║  ║ ║  ║ ║  ║ │
│  ╚══╝ ╚══╝ ╚══╝ ╚══╝ ╚══╝ ╚══╝ │
└──────────────────────────────────┘
         ← COLLAR (pasa por dentro →
           de los 6 túneles)
```

- **Laterales:** la funda abraza los 4 cantos del tracker con un grosor de ~2mm. La textura geométrica (Y-shape o colmena) recorre los laterales para mejorar el agarre.

### Cómo funciona

1. El tracker se introduce en la funda a presión (el TPU se estira ligeramente)
2. El collar del perro se pasa por los 6 túneles de la celosía trasera
3. Se cierra el collar normalmente — la celosía queda atrapada entre el collar y el cuello del perro
4. Para cambiar de collar o quitar el tracker: se abre el collar, se desliza fuera de los túneles

### Sistema anti-caída

La funda agarra el tracker por **3 mecanismos simultáneos**:

| Mecanismo | Descripción |
|-----------|-------------|
| **Fricción TPU** | La funda es ~0.3mm más pequeña que el tracker. El TPU se estira para abrazarlo. |
| **Muescas laterales** | El tracker tiene pequeñas ranuras en los 4 cantos. La funda tiene resaltes que encajan en esas ranuras como un puzle. |
| **Reborde frontal** | La funda se dobla 1mm sobre el borde frontal del tracker, como una funda de móvil. Esto impide que el tracker salga hacia adelante. |

### Material

- **TPU 85A-90A** (poliuretano termoplástico) con aditivos UV
- Grosores: 2mm laterales · 1.5mm trasera · 1mm reborde frontal
- Color: verde militar/oliva (o el que se venda)
- Coste estimado: ~1-2€/unidad en molde de inyección

## OPCIÓN F — BUMPER PERIMETRAL + CELOSÍA TRASERA

### Cómo se ve

El tracker NO va envuelto. Lleva un **bumper** (aro) de TPU que solo agarra los 4 cantos y se extiende en la parte trasera formando la celosía. La cara frontal queda **completamente al aire**.

```
VISTA FRONTAL (lo que ve el dueño):

┌──────────────────────────────────┐
│ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒  │  ← bumper solo en los
│ ▒                              ▒ │     bordes (3mm)
│ ▒                              ▒ │
│ ▒         TRACKER              ▒ │
│ ▒         COMPLETO             ▒ │  ← TODO visible
│ ▒         Ls incluidas         ▒ │     sin recortes
│ ▒                              ▒ │
│ ▒                              ▒ │
│ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒ ▒▒  │
└──────────────────────────────────┘

         ↑ las Ls están 100% al aire
```

```
VISTA TRASERA (contra el collar):

┌──────────────────────────────────┐
│ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒  │
│ ▒                              ▒ │
│ ▒   ╔══╗ ╔══╗ ╔══╗ ╔══╗ ╔══╗  ▒ │  ← celosía trasera
│ ▒   ║  ║ ║  ║ ║  ║ ║  ║ ║  ║  ▒ │     con 5-6 túneles
│ ▒   ╚══╝ ╚══╝ ╚══╝ ╚══╝ ╚══╝  ▒ │
│ ▒   ╔══╗ ╔══╗ ╔══╗ ╔══╗ ╔══╗  ▒ │
│ ▒   ║  ║ ║  ║ ║  ║ ║  ║ ║  ║  ▒ │
│ ▒   ╚══╝ ╚══╝ ╚══╝ ╚══╝ ╚══╝  ▒ │
│ ▒                              ▒ │
│ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒  │
└──────────────────────────────────┘
```

```
CORTE LATERAL (perfil del conjunto):

   ┌──────────────────────────────┐
   │   TRACKER                    │
   │   (cara frontal visible)     │
   └──────────────────────────────┘
   ┌──────────────────────────────┐ ← BUMPER TPU agarrando
   │ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒  │    los cantos + reborde
   │ ▒   CELOSÍA TRASERA       ▒ │    1mm en frontal
   │ ▒   ╔══╗ ╔══╗ ╔══╗ ╔══╗  ▒ │
   │ ▒   ╚══╝ ╚══╝ ╚══╝ ╚══╝  ▒ │
   └──────────────────────────────┘
            ↑ COLLAR →
```

### Cómo funciona

1. El bumper se encaja en el tracker: primero se colocan las 4 esquinas, luego se presiona el resto del perímetro
2. Los dientes internos del bumper encajan en las muescas de los cantos del tracker — asegurando que no se salga
3. El collar pasa por los túneles de la celosía trasera (igual que en opción A)
4. Para quitar: se presiona una esquina del bumper y se desencaja

### Sistema anti-caída (corner grip)

Aquí está lo que te gusta — las esquinas como punto de agarre:

Las 4 esquinas del tracker tienen **dientes/resaltes de bloqueo** moldeados en la propia carcasa ABS/PC. El bumper tiene cavidades que encajan exactamente en esos resaltes.

```
ESQUINA DEL TRACKER (ampliado):

         ┌─────────────────────────┐
         │                         │
         │    TRACKER              │
         │                         │
         │         ┌────────┐      │
         │         │ DIENTE │      │  ← resalte integrado
         │         │ TRACKER│      │     en carcasa ABS/PC
         │         │ (2mm)  │      │
         │         └──┬─────┘      │
         └────────────┼────────────┘
                      │
                 ┌────┴─────┐
                 │ CAVIDAD  │       ← bumper TPU encaja
                 │ BUMPER   │          sobre el diente
                 └──────────┘
```

**Por qué no se rompe:**

| Aspecto | Detalle |
|---------|---------|
| Material | El diente es **ABS/PC** (lo que la carcasa tiene, no una pieza aparte) |
| Unión | El diente NO es una pieza añadida — es parte del molde de la carcasa |
| Base redondeada | Radio de 0.5mm en la base del diente (sin esquina viva = no se concentra tensión) |
| Grosor | 2mm de base, 1.5mm en punta |
| Ángulo | Ligera inclinación de 5° hacia dentro (el diente "muerde" el TPU) |
| 4+ por esquina | En cada esquina hay **3-4 dientes**. Si uno se rompe, los otros sujetan |

```
VISTA ESQUINA — MÚLTIPLES DIENTES:

   ┌──────┐
   │ TRACK│  ← 4 dientes en la esquina
   │   ┌┐┌┐│     (vistos desde arriba)
   │   │││││
   │   └┘└┘│
   └───────┘
```

### Comparativa de seguridad mecánica

| Situación | Opción A (funda completa) | Opción F (bumper) |
|-----------|:---:|:---:|
| Rama golpea el dispositivo | ✅ La funda protege | ✅ El bumper protege cantos |
| Mordida de perro | ✅ TPU absorbe | ⚠️ El tracker frontal queda expuesto |
| Tirón fuerte del collar | ✅ 6 pasadores distribuyen | ✅ 6 pasadores distribuyen |
| Caída al suelo | ✅ Funda absorbe | ⚠️ Solo cantos protegidos |
| Se engancha en una rama y tira | ✅ Sin dientes expuestos | ⚠️ El bumper puede desencajarse lateralmente |
| Exposición UV 2 años | ✅ TPU se degrada lento | ⚠️ Menos TPU = menos degradación |
| Ls visibles | ⚠️ Recortes necesarios | ✅✅ 100% libres |

### Material

- **Bumper: TPU 85A-90A** UV-resistant (igual que opción A)
- **Celosía trasera: TPU 85A-90A** — misma pieza que el bumper
- **Dientes en carcasa: ABS/PC** — integrados en el molde del tracker
- Coste estimado: ~1.5-2€/unidad (ligeramente más caro que A por los dientes más finos)
