# DESCARTADO — Funda con doble lengüeta (side-release) + O-rings / correa NATO

**Concepto:** clip con doble lengüeta tipo hebilla de mochila para sujetar el tracker, fijado al collar con O-rings de goma o una correa de goma con ojales (tipo NATO).

**Por qué era atractivo:** mecanismo ultra-probado (hebilla de mochila), antiatasco, barato, anti-perro (dos lengüetas), universal.

**Por qué se descartó:**
- **La funda tapa parte del tracker** y suma volumen/peso.
- El usuario prefirió una solución **más integrada en el propio dispositivo** (goma que entra dentro del GPS) en vez de una funda externa.
- La correa/hebilla sobresale (mordible, se engancha).

**Sustituido por:** goma en U que se integra dentro de las esquinas del GPS — más limscia, más ligera, sin funda que tape las luces.

**Nota:** este concepto sigue siendo el mejor **plan B** si la goma en U diera problemas de fabricación. Es el más probado de todos.
