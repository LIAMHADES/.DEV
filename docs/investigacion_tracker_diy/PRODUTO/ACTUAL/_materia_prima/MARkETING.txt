## **🚗 ANTI-FRAUDE GPS: DETECTAR COCHE vs CAMINATA REAL (v4.0)**

**Tecnología:** **Bosch BMI270** + Sensores del Teléfono.

El BMI270, con su contador de pasos y detección de gestos, es clave para diferenciar el movimiento real del perro de un viaje en coche, asegurando que los rankings y calorías sean precisos.

```cpp
// Lógica de Firmware con BMI270
if(gps.speed.kmph() > 25 && bmi.isStationary()) {
  movement_type = "CAR"; 
  km_valid = 0;
} else if (gps.speed.kmph() < 20 && bmi.stepCount() > last_step_count) {
  movement_type = "WALK_RUN";
  km_valid += delta_km;
  last_step_count = bmi.stepCount();
}
```
