# ⚡ **OPTIMIZACIÓN Y LÓGICA DE FIRMWARE (v3.7)**

## **🎯 LÓGICA INTELIGENTE DEFINIDA**

El firmware implementa una máquina de estados para optimizar el consumo:

```
VELOCIDAD (detectada por BMI270) → INTERVALO GPS
>15km/h  → cada **3s**   (MODO RUN)
5-15km/h → cada **5s**   (MODO Trote)
<5km/h   → cada **10s**  (MODO PASEO)
<1km/h   → **DEEP SLEEP** (MODO REPOSO, consumo <15µA)

ZONA WIFI CONOCIDA → GPS OFF (Ahorro máximo)
FUERA ZONA SEGURA → Alerta + Tracking intensivo
```

## **🚀 IMPLEMENTACIÓN CÓDIGO (Ejemplo)**

El código utiliza el sensor **Bosch BMI270** para un control de movimiento preciso.

## **🏆 COMPARATIVA Y ELECCIÓN FINAL DE COMPONENTES (v3.7)**

Este resumen justifica la elección de los componentes finales sobre las alternativas investigadas.

### **1. PLACA PRINCIPAL: LilyGo T-SIM7000G S3**
*   **Por qué gana:** Ofrece la mejor relación **integración-precio-facilidad**. Tener MCU, GPS y Módem en una sola placa simplifica enormemente el diseño del PCB y reduce las fuentes de error. Es superior a la combinación `Quectel BG96 + ESP32` en términos de simplicidad para la producción.

### **2. SENSOR IMU: Bosch BMI270**
*   **Por qué gana:** Sus funciones de IA integradas, como el **contador de pasos (step counter)** y la detección de estado estacionario, son mucho más fiables que un `MPU6050` básico para implementar la lógica de "despertar por movimiento" y el antifraude.

### **3. ANTENA: Ignion A101 + LNA**
*   **Por qué gana:** La adición de un **Amplificador de Bajo Ruido (LNA)** proporciona la máxima sensibilidad de señal posible, logrando una precisión inferior a 1 metro en condiciones ideales, lo cual es un diferenciador clave del producto.

### **4. CARGADOR: Magnético + BQ24040 TI**
*   **Por qué gana:** Ofrece la mejor **experiencia de usuario** (comodidad) y la **máxima impermeabilización (IP68)** al eliminar por completo el puerto USB-C externo, que es un punto de fallo común.
