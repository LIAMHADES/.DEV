## **🎨 SISTEMA DE ILUMINACIÓN ARES (v4)**

El diseño se basa en 12 LEDs analógicos de alta intensidad para formar dos "L" visibles a más de 50m, con un color uniforme y controlado por software.

*   **Hardware:** 12x LEDs SMD 1206 (2R, 2G, 2B por cada una de las dos "L").
*   **Alimentación:** Directa desde la batería (VBAT 3.0-4.2V) con resistencias limitadoras. **No se usa un conversor/booster**.
*   **Control:** 3 canales PWM (R, G, B) que controlan 3 MOSFETs N-Channel, permitiendo una mezcla de colores completa.
*   **Sensor de Luz:** **Eliminado**. El brillo se gestiona por un "Astro-Reloj" vía software (hora local del GPS).
*   **Detalles de implementación:** Para información sobre la calibración de color, óptica y prevención de "ghosting", consultar `docs/investigacion_tracker_diy/PRODUTO/ARES_HW_V4_Especificacion_Medium_Large.md`.

## **💾 CÓDIGO FIRMWARE: CONTROL DE LEDS v4**

```cpp
// ARES v4.0 - Control de LEDs analógicos vía MOSFETs
#define BMI270_SDA 21
#define BMI270_SCL 20

// Pines de control para las puertas (gate) de los MOSFETs
#define LED_R_GATE_PIN 16
#define LED_G_GATE_PIN 17
#define LED_B_GATE_PIN 18

// Canales PWM del ESP32
#define PWM_R_CHANNEL 0
#define PWM_G_CHANNEL 1
#define PWM_B_CHANNEL 2

void setup_led_pwm() {
  // Configurar canales PWM a 2kHz
  ledcSetup(PWM_R_CHANNEL, 2000, 8); // Canal, Frecuencia, Resolución (8-bit = 0-255)
  ledcSetup(PWM_G_CHANNEL, 2000, 8);
  ledcSetup(PWM_B_CHANNEL, 2000, 8);

  // Asignar pines a los canales PWM
  ledcAttachPin(LED_R_GATE_PIN, PWM_R_CHANNEL);
  ledcAttachPin(LED_G_GATE_PIN, PWM_G_CHANNEL);
  ledcAttachPin(LED_B_GATE_PIN, PWM_B_CHANNEL);
  
  // Añadir resistencias de 100k Ohm (pull-down) en el PCB para evitar "ghosting"
}

void setup() {
  // ... resto del setup ...
  setup_led_pwm();
  Serial.println("✓ ARES HARDWARE v4.0 FUNCIONAL");
  Serial.println("• Carga: Magnética Externa");
  Serial.println("• LEDs: 12x SMD 1206 vía MOSFETs");
}

// Función para controlar el color aplicando la calibración de blancos
void set_led_color(int red, int green, int blue) {
  // Aplicar factor de corrección para un blanco puro
  float r_calib = red * 0.60;
  float g_calib = green * 0.90;
  float b_calib = blue * 1.0;

  ledcWrite(PWM_R_CHANNEL, (int)r_calib);
  ledcWrite(PWM_G_CHANNEL, (int)g_calib);
  ledcWrite(PWM_B_CHANNEL, (int)b_calib);
}
```
